# NPC与3D物料使用说明

- 从`NPC独立物料/index.html`打开六名角色包，每人独立文件夹含代码头像、Markdown剧本和可打印HTML。
- NPC后台增加“我的NPC剧本”；GM“NPC档案”里查看演员剧本和模型制作要求。演员只能收到自己剧本，GM可查看全部。
- 从`3D模型制作需求/3D模型制作总需求.md`查看13类模型要求；每类另有独立制作单及完整证据编号CSV。
- 正式GLB尚待生成；已接入固定文件名与示例模型回退。后续热点交互需按制作单实现。
- 当前使用源为`server/story-materials.json`；更新后运行`npm run export:materials`重新导出物料。
- 本次以用户提供故事稿为准统一角色公开身份，保留代码旧ID，头像全部沿用代码现有文件，不重绘。
- 新版本迁移仅更新未被GM改动的旧默认文字；已有自定义文案需GM对照新版资料审核。
