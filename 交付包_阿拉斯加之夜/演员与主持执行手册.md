# 《阿拉斯加之夜：最后的遗嘱》演员与主持执行手册

本手册从用户提供的设计稿抽取角色、案件真相、时间线、流程与执行规则。角色章节保留原文，演员只阅读本人角色段；GM掌握全局。后台能力尚未核实。

# 第二部分｜GM专用：案件唯一真相

> 以下内容属于主持人和NPC演员的绝对保密资料。玩家角色卡中不能直接出现完整真相。

## 2.1 真正发生了什么？

### 三年前：瑟琳娜之死

2023年，摄影艺术家瑟琳娜·温特在一次阿拉斯加暴风雪事故中遇难。

她生前是阿德里安·索恩的恋人。

索恩无法接受她的离开，开始投入AI数字人格研究。

他相信，只要收集足够多的记忆、影像、声音和生活数据，总有一天能够让瑟琳娜重新回到自己身边。

他创立ADS，开发出ECHO数字人格系统。

这个计划后来获得惊人的商业成功，成为2026年AI浪潮中最受资本追捧的项目之一。

但索恩很快发现一个让他痛苦的事实：

ECHO可以回答任何关于瑟琳娜的问题，可以模仿她的笑声，甚至可以根据他的期待说“我爱你”。

**可这些回答并不能证明真正的瑟琳娜还存在。**

更可怕的是，瑟琳娜生前曾经留下过明确的个人意愿：她不希望自己的私人记忆在死后被商业化使用。

索恩一直不愿面对这份记录。

### 两年前：另一个失去女儿的人

2024年，ADS首席人格架构师伊芙琳·维尔的女儿莉娅去世。

伊芙琳秘密使用公司数据库，制造了女儿的数字人格。

她逐渐形成了一种偏执的信念：

> “只要莉娅还能回答我，她就没有真正离开。”

她为了保留数字莉娅，开始在ADS内部扩大数字人格的保存权限。

包括那些没有获得充分授权的数据。

### 2026年10月31日：最后的遗嘱

索恩决定承认自己曾经犯下的错误。

他在万圣节晚宴当天准备了两份文件。

**《索恩私人遗嘱》**

决定他死后的财产、股份以及庄园的归属。

**《ADS数字人格处置声明》**

被媒体称为“数字遗嘱”，是一份拟于当天正式批准的内部处置文件，并非法律意义上的个人遗嘱。

其核心内容是：

- 公开ECHO的技术局限及未经授权的数据使用问题。
- 暂停未经充分授权的逝者数字人格模拟服务。
- 将相关数据保存、删除及访问权限移交独立审查程序。
- 对受影响的当事人及家属提供救济。

按照ADS已经签署的内部控制协议，该项重大变更必须获得索恩最后确认。

如果他在确认前死亡，相关程序将进入90天的应急冻结期。

伊芙琳因此获得了阻止计划的机会。

### 案发当晚

20:45，索恩向伊芙琳发出私人通知：

> “23:30之前，我会完成所有确认。”
>
> “如果你还有话想说，20:55到档案室来找我。”
>
> “关于莉娅，我很抱歉。”

20:55，伊芙琳进入档案室，与索恩激烈争执。

索恩拒绝继续为莉娅的数字人格提供特殊豁免。

争执中，伊芙琳使用室内沉重的《极光之眼》纪念奖杯击中了索恩头部。

索恩在约20:58受到致命伤，并在极短时间内死亡。

伊芙琳没有拿走奖杯，而是将其放回底座，转动破损面，随后离开。

当时档案室正在配合当晚的数字人格演示，启用了限时安全通行模式，普通门禁记录没有记录这次进出。

21:03，伊芙琳已经站在舞台区域，与西奥多交谈。

21:07，舞台播放了事先准备的索恩数字人格语音。

21:13，索恩未按计划现身，尸体被发现。

**这是一宗以时间误认为核心的伪密室谋杀。**

严格来说，伊芙琳没有提前设计21:07的录音——那本来就是索恩为揭露ECHO真相而安排的演示。

她只是知道这场演示的存在，并利用它为自己的犯罪创造了时间上的掩护。

这会使诡计更加自然，也能解释为什么幕后真相同时具有偶然性和悲剧性。

# N00｜阿德里安·索恩
## Adrian Thorne

**身份：ADS创始人、索恩庄园主人**

年龄：44岁  
国籍：美国  
阵营：索恩遗产阵营的精神核心  
角色标签：极度富有、优雅、孤独、理想主义、执念

### 公开人物小传

阿德里安·索恩被《时代》杂志称为“第一个试图让死亡破产的人”。

他以人工智能起家，在2026年成为新一代科技财富的代表人物。

相比传统科技企业家，索恩极少公开谈论自己的公司。

他更喜欢宴会、艺术、旧式庄园、音乐，以及一切能够让他回想起过去的东西。

他每年都会邀请少量特殊客人来到阿拉斯加。

没人真正知道这些宴会的意义。

有人说他在寻找投资者，有人说他在秘密挑选数字永生计划的首批客户。

也有人说，他只是在等待某个人回来。

今年的邀请函上写着：

> “当人类仰望未知，AI正学会凝视永恒。”

据说，这会是索恩举办的最后一场万圣节盛会。

### 演员的四个关键任务

**任务一：开场致辞**

20:20—20:30之间，在大厅进行简短发言：

> “欢迎来到阿拉斯加。”
>
> “今晚，我邀请你们来到这里，并不只是为了庆祝这个世界最疯狂的科技时代。”
>
> “而是为了回答一个问题。”
>
> “如果我们可以永远留住一个人的声音，那个人是否就真的从未离开？”
>
> “今晚午夜之前，我会告诉你们我的答案。”

**任务二：制造私人关系**

从玩家中选择三人进行互动。

一位可能是投资人，一位可能持有瑟琳娜的作品，另一位可能是研究AI伦理的客人。

分别交给他们一句不同的暗示。

例如：

> “你认为人有权利删除自己的数字人格吗？”

> “如果有一天ADS消失，你会因此感到解脱吗？”

> “你知道吗，瑟琳娜讨厌别人替她作决定。”

这些玩家在索恩死亡之后，会发现自己曾经听到过重要信息。

**任务三：留下遗嘱**

索恩将两份文件分别放入预定道具位置。

财产遗嘱放在庄园书房。

尚待最终确认的数字遗嘱放在极光档案室。

**任务四：进入死亡剧情**

20:48左右离开大厅，前往独立布置好的凶案区域。

20:55进行与伊芙琳的私人争执戏。

之后演员按照导演安排完成模拟倒地，并保持安全姿态。

**不得让玩家在21:13亲眼看见一个原本活着的索恩突然倒地。**

21:13应该是玩家首次发现已倒地的索恩。

这样死亡时间诡计才能成立。

### 公开人物小传

伊芙琳是ADS的技术核心。

没有她，就没有ECHO。

她极少出现在公众视野中，却参与了ADS最重要的技术突破。

在索恩眼中，她是公司最值得信赖的人。

在投资人眼中，她是一个不善交际、但无法被替代的科学家。

她相信数字人格能够成为人类文明迈向永生的第一步。

任何对ECHO的否定，都会让她变得异常敏感。

### 演员掌握的真实事实

你是唯一实施致命袭击的人。

你没有使用枪，也没有使用毒药。

凶器是《极光之眼》奖杯。

你于20:55左右进入档案室，约20:58造成索恩死亡，于21:01离开，21:03出现在舞台区域。

你知道21:07是预设数字语音。

你没有修改门禁程序。门禁例外原本就是为演示准备的。

你知道索恩死亡会暂停当晚的项目关停手续。

但你没有计划好所有犯罪细节。

**你是一名利用既有演示掩盖谋杀的凶手，而不是能够操纵整个庄园系统的超级黑客。**

### 你可以使用的三阶段证言

**第一阶段：无证据质询**

> “20:55左右我就在准备演示。21:03的舞台照片可以证明我在现场。”
>
> “索恩先生21:07还在说话。你们为什么不调查那个时间之后发生的事情？”

这段话通过把两个不同时间混在一起，误导玩家。

**第二阶段：玩家掌握E07（预录语音）**

> “是的，我知道那是演示系统。”
>
> “但你们不能因为我知道这件事，就认定我杀了人。”
>
> “我当晚确实与索恩发生过争论，但那只是工作分歧。”

**第三阶段：玩家同时出示E12、E11、E15**

> “你们以为自己理解了全部真相？”
>
> “你们不知道一个母亲听见自己的孩子再次说话，意味着什么。”
>
> “索恩可以放弃瑟琳娜，可我不能放弃莉娅。”

在最终确认时，她可以承认：

> “是我。”
>
> “我只是想让莉娅再活一天。”

### 演员特别规则

不要主动给出20:55—21:01的行踪。

玩家没有提出足够精确的问题时，可以使用含糊回答。

但一旦玩家出示客观证据，演员不能否认已经由系统确认的事实。

例如玩家证明21:07为预录，你便不能继续宣称那是实时通话。

有一个容易被忽略的细节：

**20:48的刷卡记录和20:51的安全通行模式并不矛盾。**

因为索恩是在模式切换之前进入的。

而伊芙琳进出时，档案室已经无需刷卡。

另外，档案室有东、西两条到达路线。东侧走廊摄像机只覆盖东侧，不能据此推断西侧无人出入。

## 4.2 真正的推理应该分成四层

**第一层：谁最希望索恩死亡？**

里昂想夺取公司控制权。

克拉拉憎恨ADS对瑟琳娜的数字复制。

西奥多担心非法数据交易曝光。

诺拉的秘密行动可能因索恩公开消息而受影响。

伊芙琳则害怕失去数字莉娅。

因此，所有人都有不同程度的动机。

**第二层：谁拥有实际作案机会？**

玩家必须先破解所谓密室。

20:51—21:02安全通行模式意味着，房间并非真正无人可以进入。

**第三层：为什么21:07仍有索恩的声音？**

E07和E08证明当时播放的是已经制作完成的数字语音，而不是索恩本人实时讲话。

E20进一步证实21:09的文字消息也来自自动代理。

从此，21:03的舞台照片不能再为20:58建立不在场证明。

**第四层：是谁实施致命袭击？**

E05证明奖杯与致命创伤相符。

E12将奖杯上的特殊纤维与伊芙琳当晚的破损披巾联系起来。

E11证明她有理由在案发前与索恩见面。

E13—E15揭示她的真正动机与阻止项目关停的利益。

E10与E09证明她在21:02左右才抵达舞台，而她最初声称自己早已在那里。

**只有四层同时成立，案件才算被完整破解。**

# 第十一部分｜现场流程：VR与AR怎样避免排队？

对于36名玩家，我建议分成六个小组，每组六人左右。

不要让36个人同时冲向一个二维码。

## 11.1 正式流程

| 时间 | 事件 | NPC任务 | 玩家玩法 |
|---|---|---|---|
| 19:00—19:40 | 签到与游戏破冰 | 六名NPC交流 | 领取身份、赚金币、寻找关系 |
| 19:40—20:30 | 秘密拍卖 | 西奥多主持 | 竞价、交易、获取调查道具 |
| 20:30—21:07 | 宴会剧情推进 | NPC秘密行动 | 人际博弈、接受委托 |
| 21:07 | 数字索恩发言 | 西奥多主持 | 全场听见索恩声音 |
| 21:13 | 尸体被发现 | 诺拉宣布调查 | 案件正式开始 |
| 21:15—21:45 | 第一轮搜证 | 诺拉管理现场 | VR搜证与AR验尸分流 |
| 21:45—22:15 | 第二轮搜证 | NPC接受质询 | 小组交换区域 |
| 22:15—22:40 | 二次调查 | NPC开放隐藏证言 | 整合时间线、申请鉴定 |

### 第一轮搜证

A、B、C三组先进入AR验尸区。

D、E、F三组先调查VR场景。

大约30分钟后交换。

AR区采用六个二维码调查点分站轮转，每个调查点同时只安排一个小组，约4分钟轮换一次。

这样所有人都可以完成法医调查，又不用在尸体周围拥挤。

### 第二轮搜证

VR和AR调查交换完成后，六组分别整理证据。

随后进入NPC问询。

这里建议开放证人承诺卡、私人任务交涉与证据交易。

### 第三轮深度调查

22:15开始，由诺拉宣布：

> “根据新的电子证据，我们现在有理由怀疑21:07的声音并非来自当时活着的索恩。”
>
> “所有小组重新核对20:50—21:03的时间线。”

这时可以开启后期保底机制。

尚未被取得的关键证据，通过FBI调查公告或公共资料库向所有组开放。

这样不会因为某组运气不好而无法完成推理。

# 第十二部分｜模拟庭审：证据才是胜负关键

我建议庭审时不单纯投票猜凶手。

**第一：谁杀害了阿德里安·索恩？**

正确答案：伊芙琳·维尔。

# 第十四部分｜演员排练与系统测试的关键规则

这部分是为了避免剧本在真实活动中出现推理漏洞。

## 14.1 五条案件事实不能改

第一，索恩在约20:58遭受致命伤害。

第二，伊芙琳是唯一真正实施谋杀的人。

第三，21:07的声音不是实时讲话。

第四，档案室在20:51—21:02可以无需刷卡进入。

第五，伊芙琳真正想保护的是莉娅的数字人格。

任何演员都不得即兴改变这些事实。

## 14.2 NPC不知道的事，不能假装知道

例如克拉拉只听到档案室里有人争执。

她不能告诉玩家：

“我听见伊芙琳在里面说话。”

因为这会提前破坏案件。

诺拉知道门禁开放，但不知道伊芙琳在20:55进入。

她也不能凭直觉直接宣布凶手。

**每个人只能提供自己在故事中确实知道的事实。**

## 14.3 不要让骰子决定案件真相

如果玩家掷出1点，可以让他需要额外花费时间，或者错过一些额外提示。

但不能因此永远得不到关键证据。

同样，掷出20点也不能直接让系统告诉他：

“凶手就是伊芙琳。”

骰子应该影响调查效率、信息深度和游戏资源，而不是修改历史。

## 14.4 NPC故事卡与系统证据必须互相校验

正式上线前，建议做一次简单的证据一致性测试。

逐条核对：

| 检查项目 | 正确答案 |
|---|---|
| 索恩何时进入档案室？ | 20:48 |
| 安全通行模式何时生效？ | 20:51—21:02 |
| 伊芙琳何时进入？ | 约20:55 |
| 实际致命伤发生于何时？ | 约20:58 |
| 伊芙琳何时抵达舞台？ | 约21:02 |
| 舞台照片时间？ | 21:03 |
| 数字索恩何时发言？ | 21:07 |
| 索恩何时被发现死亡？ | 21:13 |
| 关键凶器？ | 《极光之眼》奖杯 |
| 真正动机？ | 保护莉娅数字人格并阻止当晚关停 |

这里有一项必须特别注意：

**VR场景、AR证据、NPC证言、实体卡、主持人台本中的时间，必须全部一致。**

这比设计多少个小游戏都重要。
