# 《阿拉斯加之夜：最后的遗嘱》一页读懂

> **GM／导演专用，含凶手和全部诡计。不要发给玩家。**本页依据现有《演员与主持执行手册》和 `server/story-materials.json` 整理；执行时间以活动控制台为准。

## 先用一句话理解

一群宾客受富豪索恩邀请，来到阿拉斯加庄园参加万圣节晚宴和拍卖。主人本想当晚公开自己的 AI 数字人格项目 ECHO 的问题，却在揭晓前被项目负责人伊芙琳杀害。众人听见“死者”在 21:07 说话，以为他当时仍活着；实际那是提前安排的数字语音。六组玩家搜证、质询证人，在庭审中还原死亡时间、凶手与动机，最后再决定 ECHO 应如何处理。

## 开场前发生了什么

- 三年前，摄影师**瑟琳娜**在阿拉斯加离世。恋人**阿德里安·索恩**创办 ADS、开发 **ECHO**，试图用声音、影像和记忆重现她。
- **伊芙琳**是 ECHO 的首席人格架构师。她的女儿**莉娅**后来去世；伊芙琳秘密保存了女儿的数字人格，并把它当成最后的精神寄托。
- 索恩逐渐意识到：会回答问题的模拟人格不等于逝者本人，项目还使用了未经充分授权的私人数据。他准备在宴会上承认问题，暂停相关服务，并交由独立程序审查。
- 根据故事里的 **ADS 内部控制协议**，索恩必须亲自作最终确认；若他确认前死亡，相关处置会进入 **90 天应急冻结**。伊芙琳害怕数字莉娅被关闭，因此必须阻止他。

## 案件的三个关键问题

1. **他何时、怎样死？**约 **20:58** 在档案室被《极光之眼》奖杯击中头部，不是 21:07 后才遇害。看法医与伤情（EV-001、EV-005、EV-021）。
2. **21:07 为什么还能说话，门禁为何像“密室”？**声音来自事先导出的 ECHO 文件（EV-007、EV-008）；20:51—21:02安全通行模式下进出不需普通刷卡，东侧摄像头也拍不到西侧通道（EV-003、EV-017、EV-018）。
3. **怎样锁定伊芙琳？**索恩约她在案发前见面（EV-011），奖杯上的纤维与她破损的披巾相符（EV-012），她约21:02才到舞台（EV-009、EV-010），数字莉娅与处置声明、90天冻结条款解释她的动机（EV-013—EV-015）。

**常见误解：**21:03伊芙琳在舞台的照片只证明她那时到了舞台，不能证明20:58也在那里；索恩20:48的刷卡记录发生在门禁切换之前，两者不矛盾。

## 玩家究竟在玩什么

开场先认识人物和各自想要的东西；拍卖与交谈让各组获得资源；命案后六组轮换调查、交换证据、质询 NPC；庭审时各组提交完整指控，回答**凶手、死亡方式与时间、21:07的声音、门禁、动机**五项。公布凶手后，最后一轮讨论的是：ECHO 的数字人格应该保留、封存审查，还是停止模拟。

现场播控的简化顺序为 **B01背景 → B02万圣节投屏 → B03人物出场 → B04拍卖规则 → A02索恩正式登台 → A04数字语音 → A05发现遗体 → 调查 → B05庭审规则 → A10真相重建 → A11遗言音频 → A12结尾**。具体解锁条件见 `现场演绎音频/使用说明_先读.md`。A11是原“真实遗言视频”情节的**音频替代**，不是真人录像。
