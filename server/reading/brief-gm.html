01 · 故事从哪里开始

基础故事 / 四个动作

万圣节夜，受邀宾客来到阿拉斯加深处的索恩庄园。主人阿德里安·索恩创办的 ADS 公司研发了 ECHO：一种能用逝者资料模拟其声音和回答的系统。他承诺在午夜前说明一件重要的事。晚宴先有拍卖、交谈与秘密委托；随后一宗命案把每位来客卷入调查。

GM 核心真相

伊芙琳是唯一凶手。她为保护亡女莉娅的数字人格，于约20:58在档案室用《极光之眼》奖杯袭击索恩。21:07的“索恩发言”是索恩自己事先安排的 ECHO 演示，不能证明他那时还活着。门禁在20:51—21:02临时免刷卡，所谓密室也只是误读。

索恩原要公开 ECHO 的技术局限与未授权数据问题，并暂停相关模拟。按故事中的 ADS 内部协议，他若在最终确认前死亡，处置程序冻结90天；伊芙琳因此获得保住数字莉娅的机会。凶手没有临时伪造21:07录音，她利用了原有演出安排。

03 · 六位 NPC 速记卡

公开身份 / 本人秘密 / 演法

阿德里安·索恩

主人 / 死者

公开：ADS创始人、庄园主人，瑟琳娜的旧爱；承诺当晚回答 ECHO 的问题。

演法：先自信迎宾，谈到“保存声音”时流露疲惫；20:48离开人群，21:13以已经倒地的状态被发现。

本人秘密：准备承认未经授权数据问题、暂停部分模拟；21:07演示由自己事先安排。不能在21:13作为活人突然倒下。

伊芙琳·维尔

ECHO架构师

公开：项目技术负责人，与索恩合作密切；重视数字人格的价值。

演法：冷静、专业，质询时要求别人拿出可核对的时间与物证。

本人秘密：唯一凶手；为保住数字莉娅，20:55进档案室，约20:58用奖杯袭击索恩，21:01离开。最初可强调自己21:03在舞台，但不能声称有20:58的不在场证明。

诺拉·里德

合规顾问

公开：外聘安全合规顾问，关注权限和现场秩序。

演法：前段低调；发现遗体后控制现场、引导六组按证据调查。

本人秘密：真实身份是 FBI 特别探员。她知道20:51—21:02的安全通行设置，但不是凶手身份的全知证人；按阶段公开身份和门禁事实。

里昂·默瑟

财务总监

公开：替 ADS 处理资本与财务，与索恩存在商业分歧。

演法：被怀疑时承认利益冲突，但坚持“想夺权不等于杀人”。

本人秘密：筹划董事会夺权；20:55—21:04在交易室参加视频会议，20:58有可核对的不在场证明。E-02制造嫌疑，E-24排除直接行凶。

西奥多·布莱克

拍卖师 / 主持

公开：主持拍卖与晚宴，善于把物品和秘密变成交易。

演法：保持场面节奏；庭审时限制陈述时间，让问题回到证据。

本人秘密：知道21:07声音是预制演示，约21:02见伊芙琳到舞台；另有私人数据交易。害怕后台记录暴露，所以不会轻易主动交代全部。

克拉拉·沃克

策展人

公开：瑟琳娜的朋友，负责庄园照片展；希望来宾认真看待瑟琳娜的作品。

演法：在艺术与记忆问题上有情绪，但回答行踪时保持具体。

本人秘密：保管瑟琳娜的生前录音和拒绝商业复制的授权声明；20:56经过东侧走廊，20:59在摄影区有记录，并非杀人者。

05 · 虚假线索与误导点

证据真实，错误来自解释

这里的“假线索”主要是真实资料被误读，或其他人物确有秘密却没有杀人。NPC 不必编造新证据；让玩家用另一条客观记录纠偏。

误导 01 / 听见声音

“索恩21:07还活着”

表象：E-15让全场听到他的声音。

纠偏：E-05证明20:41已导出并在21:07本地播放；E-16写着原定“数字发言后本人登台”。

误导 02 / 门禁空白

“没人刷卡，所以没人进出”

表象：E-03只记录索恩20:48入室。

纠偏：E-04、E-19说明20:51—21:02为免刷卡安全通行，东侧影像E-20也拍不到西侧通道。

误导 03 / 舞台照片

“伊芙琳有不在场证明”

表象：E-08显示她21:03站在西奥多旁边。

纠偏：死亡约在20:58；E-11还说明她约21:02才抵达舞台。照片不覆盖死亡时刻。

误导 04 / 自动回复

“21:09索恩还在发消息”

表象：索恩账户后来有文字回复。

纠偏：E-22指向ECHO自动代理，不是本人实时输入。

误导 05 / 商业动机

“里昂夺权，所以他杀人”

表象：E-02确实显示股权收购计划。

纠偏：E-24的交易室视频支持20:58不在场。动机不能代替作案机会。

误导 06 / 其他秘密

“克拉拉／西奥多隐瞒事实，就是凶手”

表象：克拉拉有瑟琳娜的声明；西奥多知晓预制演示且有数据交易。

纠偏：E-25支持克拉拉20:59在摄影区；西奥多的秘密解释沉默，却无法推翻伊芙琳的纤维、会面及时间证据。
