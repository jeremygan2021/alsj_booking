角色档案和语音卡加入头像、专长、赴约理由、播放进度、当前字幕与配乐开关。MiniMax提供的时间戳字幕单独持久化；旧任务缺失时间戳时，字幕明确标为估算。预设包含4首有署名的Kevin MacLeod CC BY 4.0纯音乐，并按角色气质选曲。播放、暂停、进度与背景音乐联动，手机使用WebAudio降低背景音乐音量。

确认语音按角色修订去重；无内容变化再次保存不会增加修订或重复付费。长任务的准备时限覆盖顺序请求，在发起付费TTS前再次确认任务和角色仍有效。生成语音与录音继续存放私有OSS，并保留鉴权、版本绑定和Range播放。

## 业余NPC

生成互动统一为30–60秒的开场、一个公开问题、固定回复与“交流已完成”，演员简报不超过120字。取消临时文件、复杂道具、设备操作、即兴推理和新增秘密等要求。正式阵营影响玩家公开交流倾向，不进入NPC暗号或真凶资料。

NPC后台默认显示现场提词，每幕三步与三条固定回答。暗号核验、证据链判断、供认口令、争议和终局交GM；演员按当前开放台词照读。拍品使用固定整理提示，演员无需临编情报。完整说明见 `AMATEUR-NPC-RUNBOOK.md`。

增量迁移只升级匹配旧默认值的NPC和拍品文案，保留GM自定义。已完成委托、金币、审核状态和拍卖进度不重置；已开始或已批准角色保留原玩家目标，只更新演员提示。
