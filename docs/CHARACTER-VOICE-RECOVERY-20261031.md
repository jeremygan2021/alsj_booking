# 角色语音校验与后台接续

2026-10-31（北京时间）。

## 问题与修复

模型可能返回不存在的音色 ID；原实现把文案、音色、速度和音高校验合并成一个错误，导致有效介绍也无法进入语音合成。现从实时音色目录解析 ID 或音色名称，无法匹配时使用目录中的有效声音，并规范语速与音高。文案仍执行原有长度、姓名和剧情边界检查，失败最多重试三次文字生成；全部通过并确认角色版本后才提交一次语音合成。最终失败保留具体且不含供应商敏感信息的诊断。

原异步任务依赖网页 GET 请求下载结果，玩家离开后任务不能自动落盘，十分钟后还会被直接判为超时。现生产入口启动后台接续器，启动时和每五秒扫描当前角色版本的待处理任务，最多并发三份；与网页共享正在进行的查询。旧超时记录保留的供应商任务优先恢复，POST 复用任务，不再因为十分钟未访问而重复合成。网络或 OSS 暂时失败保留任务等待重试；供应商明确失败或过期才允许重新创建。中断且未保存供应商任务编号的创建任务不会自动重新付费提交。

下载前及落库时均核对角色修订与任务令牌，防止迟到结果覆盖新角色。角色语音仍为私有 OSS 对象，原鉴权、Range、字幕与配乐接口沿用。
