# 角色查看与付费手机号核对

GM登录 `/admin` →「宾客与角色」，可以按宾客姓名、角色名或手机号搜索，并筛选已付费宾客。列表显示已保存的角色头像、姓名、审核状态、付费状态与手机号名单匹配来源。「管理」中可查看完整姓名、英文名、职业、技能、Cos来源、原始故事、赴宴动机、庄园改编、NPC双向关系、分幕目标及任务。玩家保存后即对GM可见，不必等待批准；NPC仍只可查看已批准且与自己有关的档案。

一键生成的角色先供玩家预览与修改。服务端私有保存生成关系与头像版本；原样提交时直接复用同一组NPC关系，避免二次模型生成选择不同联系人或重复收费。修改过内容时沿用正常的剧情关联生成与审核。草稿缓存不通过公开接口提供NPC私密演绎提示。

「导入付费手机号」支持CSV、TXT、TSV与表格粘贴；可附姓名，支持`+86`、空格、引号、中文数字宽度转换。每批最多2000行、100KB；先预览有效号码、重复、无效、NPC排除、已注册、未注册及将标记付费的人数，再确认导入。导入按号码去重，不清空既有名单，也不自动执行签到或发放金币。

导入确认后，已注册且待核验的匹配账号标记为已付费。未注册号码保留在名单，后续注册或登录时自动核对。已退款用户保持退款状态，NPC号码不导入。已付费号码的来源显示在列表与详情中。若需要退款，仍使用宾客详情中的退款操作；从名单移除不构成退款。

服务端使用增量表`paid_phones`，SQLite/PostgreSQL通用。仅GM可以读取、预览、导入及移除；NPC、普通玩家和公开接口不返回手机号名单。自动匹配及导入操作写入审计。

API：`GET /api/staff/paid-phones`，`POST /api/staff/paid-phones/preview`，`POST /api/staff/paid-phones/import`接收`{text,sourceName}`；移除使用`POST /api/staff/paid-phones/:phone/remove`。目前只有功能与测试名单，未导入任何真实活动付费名单。
