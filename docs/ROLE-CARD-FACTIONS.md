# 角色卡阵营简报

角色卡背面以正式分配表 `faction_assignments` 为准，固定展示阵营与任务：

| 阵营 | 阵营任务 |
| --- | --- |
| 杀手阵营 | 保护真正的凶手 |
| FBI调查阵营 | 还原故事线与作案手法，锁定并抓捕真凶 |
| 索恩遗产阵营 | 找到并抓捕杀手阵营的人 |

索恩遗产卡背面另有固定线索：「你要找到并抓捕的杀手，都有接头暗号。听说，暗号像四字一组的诗句。」只提供辨认方向，不展示具体暗号或成员身份；现有暗号保持不变。

FBI 卡背面的固定线索为：「21:07的声音，未必能证明索恩当时还活着。核对声音来源，再重排案发时间线。」对应 E-15 数字语音、E-05 播放日志及 E-16 演出脚本，引导调查者核对时间线，不直接给出凶手身份或凶器。

杀手卡另外展示本人和一位同伴现有的接头暗号。只从已付款、角色已批准且已配置暗号的正式杀手中选择同伴，按分配时间及玩家 ID 排序循环交接；两名就绪杀手互为同伴。不会重置暗号、公开完整名单或为缺席同伴编造暗号。本人待审核时隐藏暗号，同伴未就绪时提示联系 GM。其他阵营不会收到任何暗号，未分配者显示等待 GM 确认。

这些信息通过已有的本人/GM付费卡片权限返回，不进入 AI 摘要输入，不受摘要缓存或重新生成影响。网页展开完整档案也可阅读。正反面 PNG、单卡半 A4 PDF、A4 双卡及浏览器打印共用同一份绘制内容。

已下载的静态文件需要重新打开角色卡并下载/打印；旧二维码继续登录原宾客账号并进入 `/play`。

验证：`tests/role-cards.test.js` 覆盖正式阵营、循环交接、票务/审核过滤、暗号更新及残留暗号隔离；`tests/role-card-summary.test.js` 检查私密信息不进入模型；`tests/browser/role-cards.spec.js` 覆盖真实暗号预览、PNG/PDF 导出和扫码登录。导出 PDF 经 Poppler 渲染检查。
