# 3D 搜证试点操作说明

本版提供摄像头图像定位、实际 GLB 模型、射线点击搜证、3D 预览及打印海报。模型和定位图由本项目生成，MindAR 1.2.5 MIT 运行时随站点托管，Three.js 0.160.1 由 Vite 按需打包。

## 入口

- `/ar/demo`：公开体验，三个演示证物仅保存在本次页面状态，不写正式证据册。
- `/ar/wall-study`：正式搜证，须玩家登录、付款核验、签到、角色审核通过且第三幕开放。
- `/ar/target`：定位海报展示、下载和打印。

默认正式场景将三个热点分别绑定 E-01、E-02、E-03。这是试点模板；上线正式活动前，GM须按真实布景确认位置及剧情证据映射。模型为通用证物柜，不代表已重建现场房间。通过 `AR_SCENES_FILE` 可覆盖正式场景；公开体验仍使用内置示例。

## 现场使用

1. 打开 `/ar/target`，A4 纸按100%比例打印，不要选择“适应页面”。整图宽18厘米、高24厘米，保留边框，平整贴墙。
2. 用手机系统扫码打开 `/ar/demo`，点击“开启摄像头搜证”；对准**整张海报**，而非只对准二维码。
3. 出现“已定位墙面”后移动手机观察模型，点击金色圆环；成功收录后圆环变绿，证物内容弹出。
4. 正式玩家从证据册进入 `/ar/wall-study`；相同定位图可以用于定位该场景，点击结果写入原有证据册。
5. 海报离开镜头会隐藏模型并暂停点击。回到海报后重新定位。切后台、退出或点击关闭均停止相机。

另一个屏幕展示定位图可用于初步体验，但要匹配实际显示宽度才可检验模型物理尺寸。贴纸移动、缩放打印或墙面位置变化后，需要重新标定。当前没有离开图像后仍持续定位的 SLAM，也没有真实环境深度遮挡。

## 开发与验证

```sh
npm test
npm run build
```

生成资产：`node scripts/ar/generate-assets.js` 输出SVG海报及GLB。将本地开发站点运行在3106端口后，`node scripts/ar/compile-target.js` 使用本机 Chrome 输出PNG及真实 `.mind` 图像特征文件。资产已随代码提供，正常构建不需要重复生成。编译算法可能产生不同特征文件，海报变更后应整体发布目标文件和海报。

`scripts/ar/browser-test.js` 使用本机 Chrome 进行移动端/桌面展示、GLB点击、登录跳转、打印、图像跟踪和相机生命周期验证。需要独立测试数据库内已有 `ar-browser@example.com` / `browser-test-123` 的已签到审批玩家及第三幕；不得在生产创建该测试账号。可用 `AR_TEST_URL` 指定本地测试站点。脚本对摄像头输入注入合成视频帧，运行真实MindAR算法，不伪造定位事件；仍不能代替手机相机、现场光照和微信浏览器实测。

浏览器测试报告、截图及A4打印PDF位于 `output/playwright/ar/`，不包含在部署包中。

## 发布与回滚

使用现有站点 `https://alsj.luna.ski` 和已有 PostgreSQL，无需新建数据库或修改剧情幕数。准备的包不包含 `.env`、本地数据库、测试账号或客户录音。

```sh
# 将发布包上传至服务器 /tmp/alsj-booking-release.tar.gz 后，在服务器执行：
bash /opt/alsj_booking/current/deployment/update-ar.sh /tmp/alsj-booking-release.tar.gz
```

首次部署该脚本时，需从新发布包提取 `deployment/update-ar.sh` 到临时目录并执行，因为旧版本不包含它。脚本备份现有数据库、创建独立版本目录、构建应用、切换并检查HTTPS接口与GLB/定位文件；失败会恢复原应用。它不更新Nginx、证书或PostgreSQL服务。手工回滚遵循 `deployment/README.md`。

发布后检查公开体验、海报打印、模型和定位文件，以及正式搜证的401/403资格限制。保留原幕数，不为了试点将正式活动切到第三幕。

## 资源与后续

本版模型约33KB，定位文件约671KB，直接随静态站点发布；正式大模型可以迁移到OSS/CDN并更改 `AR_ASSET_BASE_URL`，业务接口无需修改。签名私有模型资源尚未实现，不应将秘密剧情藏在公开模型内。模型加载失败、网络超时或相机拒绝会显示恢复提示，玩家可使用3D预览；正式预览不授予证据。

手机实拍验收需覆盖 iPhone Safari、Android Chrome、微信浏览器、反光/弱光、斜角/遮挡、长时间运行和多人现场网络。完成这项验收后再确定现场可用距离、误差与帧率指标。

## 定位与探索交互更新

已加入位姿死区、时间平滑、单帧大跳变过滤与连续重新确认；识别预热8帧、丢失容忍10帧，避免短暂遮挡频繁闪现。滤波会引入轻微跟随延迟；真实手机、反光和低纹理环境仍需实拍调整。点击成功后模型约1.1秒缓缓取出，证物面板渐进展开。面板内提供独立360度查看器，可拖动旋转、双指缩放及查看背面，不改变墙面锚定坐标。
