# 业余NPC现场随身说明

供本场GM备场及NPC排练使用。每位演员只需看自己的身份与本幕提词；完整剧本留作查阅。故事中的案发时刻是证据事实，真人走位跟随GM示意，不需要演员盯钟重演。

## 一轮对话，只做三件事

1. 打招呼：“晚上好，我是____。你今晚扮演谁？”
2. 听一个公开想法：“对你来说，保留一段记忆最重要的是什么？”听完接一句：“我明白你的想法了。”
3. 看有没有对应的已有委托。没有就结束：“谢谢你的分享，接下来请跟随现场GM。”

不用记住每名玩家的长故事，也不需要临场续写共同经历。玩家说了与你的固定背景不一致的内容，可以接：“我记得的细节可能不同，我们先按今晚的角色卡继续。”

## 委托怎样确认

第一幕，玩家完成页面已经写明的动作后，在“我的NPC委托”找到这个人的对应任务，点击一次“确认完成”。先看清姓名和任务，不凭头像猜人。

只要求自我介绍、说出一个公开观点或交换一句公开信息的委托，按实际发生的动作确认。不要求玩家背原作、表演得好、说服演员或猜出隐藏答案。

旧委托如果要求道具、签字、复杂谈判、额外NPC认可或完整推理，把任务页面交给GM处理，不临时编造验收条件。页面没有对应任务时，不加任务、不口头许诺额外金币。金币由系统入账，重复点击不会重复奖励；实际到账受本场上限影响。

GM切入第二幕前集中检查未结算委托。NPC无需替玩家补票务、分组、角色审核或金币记录。

## 四幕各做一件事

| 幕次 | NPC动作 | 交给GM的事 |
| --- | --- | --- |
| 黄金舞会 | 打招呼，问一个公开问题，完成对应破冰委托 | 入场资格、任务争议和金币纠错 |
| 命运拍卖会 | 跟随主持，照读拍品说明或做一个定点动作 | 竞价、落槌、扣款、兑付效果和集资 |
| 午夜命案 | 请玩家说出E编号；照读本幕已经放行的本人证言 | 证据开放、鉴定争议和完整案情 |
| 最后的庭审 | 听陈述，按GM提示读固定回应 | 计时、证据评分、供认时机、胜负和结局 |

被追问时，始终可以说：“这一点我没有亲眼确认，我请现场GM来一起核对。”不需要用新谎言圆场，也不要把自己的猜测说成正式证据。

## 接头、道具、证言，统一这样交接

**接头：**GM在私下核对玩家身份和本人暗号，再安排与目标NPC见面。NPC只需回应：“联络已确认，请按你自己的私有简报行动。”不用背暗号名单，也不向接头者补讲完整案情。其他玩家追问时，回到自己的公开身份。

**拍品：**按现有流程在第四幕申请使用，所有效果交GM兑付。NPC只读已有说明或GM给出的那张固定提示，不负责判断“还可以问多少”“值多少金币”或临编新情报。核心证言与关键物证不作为收费谈判筹码。

**证言：**GM切幕时一次性放行本幕的证言卡。玩家问到E编号，对照本人的卡片照读，不用每次请示。卡片以外的问题、尚未放行的内容，以及“这个推论是不是已经证明”，交GM处理。供认由GM给出明确提示后再读，不让演员现场判断一整条证据链。

**鉴定失败：**请玩家保留已经取得的基础证据。需要继续核查时，请GM按已准备的固定说明处理；NPC不自行重掷、不口头更改检定，也不用补写新事实。

**道具不足：**以准备好的编号证据卡、配套音频和模型表示剧情档案。卡片写有“录像”“原片”“报告”时，不代表现场一定有另一段可播放的视频或可拆验实物；玩家要进一步查看，交GM说明。本人的服饰和装饰道具不承担临场法医鉴定。

## GM开场前准备

- 给每位NPC一张本人身份卡、一页本幕固定回应和一个明确站位；当场演练一次“打招呼—听回答—确认已有委托”。
- 指定一位GM处理规则、证据、暗号和争议；指定一位音控，或由同一位GM负责。NPC不同时承担播控和裁判。
- 按E编号准备证据卡。与动机和凶器有关的核心核查准备统一公开口径，不能因一次骰子失败就要求演员临时补救。
- 每件拍品只准备一条明确的兑付效果；效果未准备好时，开拍前改成普通收藏品，不临场出售未知情报。
- 固定登场可播放B03，演员听见自己的名字再走到定点。案发与终局由GM给提示，演员不需要计算分钟或配合真实击打；复杂动作可用灯光、静止造型和现成配音表达。
- 庭审只用一份GM评分表，全场采用同一口径。先听完玩家，再核对、宣布结果、播放终局内容。

现场只增加一句统一交接：“我请GM来确认。”不增加新的NPC审批、表演评分或道具认证环节。
