# 双面角色卡与 AI 精炼文案

北京时间 2026-10-31 01:34 发布。

## 功能

- 已付款且已建立角色的宾客可从「我的角色」或 GM「宾客与角色」打开独立工作室。
- 正面展示大幅肖像、姓名、角色身份与一句标签；背面只保留72字以内故事、最多两条26字以内行动目标、两位联系人与专属登录二维码。
- 点击生成才调用现有 LLM/MiniMax 文本接口，模型只收到玩家可见素材。字段、字数、联系人原名和剧情边界均验证。摘要保存来源哈希，资料变更后失效；缓存复用不重复请求模型，失败保留旧摘要。未配置模型时明确标记简洁模板。
- 支持翻面预览、分别下载正反面 PNG、单卡双面 PDF、两人 A4 双面合排及浏览器打印。A4 按每张纸的「两位正面、对应两位背面」配对，奇数宾客的最后半页正反均留白。采用100%原尺寸、长边翻转双面打印。
- 独立签名二维码可换取对应玩家的 HttpOnly 会话，凭证放在 URL fragment 并立即清除。退款、删除及 GM 重置均阻止后续旧码登录，不自动签到、发金币或绕过玩法权限。

## 验证

- 本地186项自动化测试通过；角色卡、后台删除及付费名单3项浏览器流程通过。
- 实际下载的 PDF 经 Poppler 渲染检查：单卡正反两页为210×148.5 mm，两位宾客为两页 A4，三位为四页 A4，浏览器打印两页 A4。正反面版式、中文和手机页面均检查；实际 A4 背面两个二维码分别解码成功，凭证不同。
- 生产候选镜像内3项相关测试在 PostgreSQL 随机独立 schema 中通过，测试 schema 随后清理，无真实模型调用或生产报名写入。
- 生产配置真实 MiniMax 测试使用虚构素材，生成64字故事与15、14字目标。
- 上线后经受控 GM 会话读取一位现有付费宾客，实际接口生成70字 AI 故事与17、18字目标；扫码登录换取正确玩家会话，签到与金币保持不变。验证临时会话随后退出，没有新增测试报名。
