# 线索配音与网页搜证

2026-10-15新增58段MiniMax speech-2.8-hd音频：26条基础证据、26条鉴定补充、6个AR节点，共15分41秒。沿用现场演绎固定音色；会面通知、证言、声明及演出台本有角色对白，内容不超出相应文字层级。配乐使用下载的Kevin MacLeod作品Long note One、Darkest Child、At Rest，CC BY4.0，播放器显示来源、授权及混音说明。

## 网页入口

扫码识别对应二维码并显示3D证物后，AR画面中的模型操作区提供紧凑播放按钮，不必展开文字。PublicAR主页面不显示线索播放器。玩家已打开的线索卡、3D物证弹层与墙面AR发现结果也使用`ClueAudio`。主动点击才加载音频；暂停/继续、重播、进度、错误重试与署名展开独立于文字搜证。同屏互斥播放，换线索或关闭卸载时释放媒体。播放期间暂停原有氛围音乐，但不覆盖用户主动暂停的偏好。

原有二维码地址不变：`/ar?clue=E-01`与`/ar?node=AR-01`等。E-15的基础演绎不解释预录来源；E-26基础仅播读线索摘要，完整遗言仍在GM终局流程播放A11。

## 媒体与权限

- `server/audio/clue-audio.json`登记58条音频，含编号、body/detail、原文SHA256、文件名、时长、角色与配乐署名。
- `server/audio/files/*.mp3`由应用服务提供，不放在Vite公开目录；Docker现有`COPY server`会包含媒体。
- `/api/ar/clues/:id/audio`、`/api/ar/nodes/:id/audio`仅公开对应基础层级。
- `/api/clues/:id/audio/:part`要求玩家有效资格与已取得该证据；detail进一步要求区域鉴定成功。
- 返回`audio/mpeg`、`nosniff`，支持字节Range；私人录音`private,no-store`。每次请求核对当前正文SHA256。GM更改文字、文件缺失或清单损坏时不返回旧录音，不影响正常文字搜证。
- 前端只接收可见层级的url、时长、角色与署名；不返回原文指纹、文件系统位置或生成密钥。生产不调用MiniMax，也不需要新增TTS凭据。

## 再制作与交付

制作流程脚本为`prepare-clue-audio.py`、`build-clue-audio.py`、`package-clue-audio.py`。先从`server/content.js`和`public-investigation.js`导出当前文本，再审核角色台本。MiniMax异步任务在`output/clue-audio`缓存，断点继续查询已提交任务，不盲目重复付费；API密钥通过临时文件或环境提供，不写入源码与发布包。混音只使用已下载配乐，不自行合成背景音乐。

交付目录`交付包_阿拉斯加之夜/线索配乐音频`含58段成片、分层台本、CSV映射、验收记录与GM试听页；完整ZIP仅交给GM，不能当作玩家公开静态资源。
