# 玩家删除与198元微信购票

2026-10-19 北京时间发布版本：`20261018T164350Z-delete-ticket`。前一版本：`20261018T163732Z`。

- GM「宾客与角色」列表和档案弹窗增加删除入口。确认后在同一事务中清除玩家、角色、媒体索引、阵营、提案及联署、任务、金币、线索、竞拍记录及登录会话；清空其未成交领先出价，成交拍品保留成交状态。不会删除其他玩家或导入的付费手机号名单。

- 首页「微信购票」及未付费玩家「去付费」显示用户提供的原始微信加好友二维码；可以保存图片。票务继续由工作人员核验，不会因打开二维码而改为已付费。

验证：175项接口及单元测试通过；删除流程在SQLite、本机PostgreSQL及生产服务器独立测试schema中通过；两个浏览器流程验证取消/确认删除、旧会话失效、重新注册、198元票价、原图字节一致及付费状态不被自动修改。线上390px手机视口验证弹窗及二维码加载，服务healthy。
